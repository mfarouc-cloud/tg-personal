# Telegram Personal — عميل تليجرام شخصي (PWA)

عميل تليجرام شخصي بمميزات قوة على طريقة Nicegram / TeleDark، يشتغل كتطبيق
ويب متقدّم (PWA) تقدر تضيفه على شاشة الآيفون الرئيسية — **من غير ماك، من غير
SideStore، من غير App IDs**. ونفس الكود يشتغل على اللينكس والويندوز.

## التشغيل (على WSL Ubuntu أو أي لينكس/ويندوز)

```bash
npm install
npm run dev     # وضع التطوير — يفتح على http://localhost:5173
# أو للإنتاج:
npm run build   # يبني في مجلد dist/
npm run preview # يخدم نسخة الإنتاج
```

### محتاج api_id و api_hash

1. ادخل على <https://my.telegram.org> → **API development tools**.
2. سجّل دخول برقمك، واعمل تطبيق، وخُد `api_id` و `api_hash`.
3. افتح التطبيق، وأدخلهم في أول شاشة. بيتحفظوا على جهازك فقط.

## التركيب على الآيفون (كتطبيق)

> لازم يكون التطبيق متاح على رابط **HTTPS** (مش localhost) عشان الـ PWA تشتغل
> كامل. أسهل طريقة: شغّله على سيرفر صغير بدومين + HTTPS (أو خدمة زي
> Cloudflare Pages / أي استضافة ثابتة لمجلد `dist/`).

1. افتح الرابط في **Safari** على الآيفون.
2. زرار المشاركة → **Add to Home Screen** (إضافة إلى الشاشة الرئيسية).
3. هيظهر بأيقونة وشاشة كاملة زي أي تطبيق.

## المميزات

### جاهزة الآن ✅
- تسجيل دخول كامل: رقم + كود + كلمة سر التحقق بخطوتين (2FA)
- قائمة المحادثات (خاص/جروبات/قنوات) + بحث + عدّادات غير المقروء
- فتح المحادثة، عرض الرسائل، إرسال نص
- استقبال لحظي (رسائل جديدة/معدّلة/محذوفة)
- **Anti-Delete**: إظهار الرسائل المحذوفة والمعدّلة بدل ما تختفي
- **Ghost Mode**: اقرأ من غير ما تبعت إشعار قراءة
- تحميل الوسائط (صور/فيديو/ملفات/صوت)
- ثيمات: داكن / **أسود AMOLED** / فاتح + لون تمييز مخصّص
- يعمل أوفلاين (Service Worker) + قابل للتثبيت (PWA)

### تحت الشغل 🔧
- إخفاء الرسائل المموّلة فعلياً (الزرار موجود، الفلترة جاية)
- نسخ النص من أي رسالة / قائمة ضغط مطوّل
- ترجمة الرسائل
- قفل التطبيق بباسكود
- مدير تحميلات + تسريع الصوتيات
- جدولة الرسائل + مجلدات
- إشعارات Web Push في الخلفية

### غير مدعوم في نسخة الويب ⚠️
- **مكالمات الصوت/الفيديو** (محتاجة WebRTC غير متاح في مكتبة MTProto للويب)
- **المحادثات السرّية المشفّرة طرف-لطرف** (غير مدعومة في المكتبة)

## التقنية
- **teleproto** (fork مصان من GramJS) للبروتوكول الحقيقي MTProto عبر WebSocket
- **Vite** + **TypeScript** + vanilla DOM (حزمة خفيفة للموبايل)
- **vite-plugin-pwa** للـ manifest و Service Worker
- الجلسة والإعدادات محفوظة محلياً (localStorage)

## الخصوصية
كل حاجة محلية على جهازك. مفيش سيرفر وسيط — التطبيق بيتصل بسيرفرات تليجرام
مباشرةً. مميزة Anti-Delete بتعتمد على كاش محلي للرسائل اللي وصلتك بالفعل.
